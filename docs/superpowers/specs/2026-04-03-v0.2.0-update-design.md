# agentskill-mcp v0.2.0 Design Spec

## Goal

Bring the MCP server in sync with the current agentskill.sh API. Fix bugs, add missing tools, expand platform support, surface security/quality data.

## Tools (8 total)

### Updated: `search_skills`

Search for skills on agentskill.sh.

**Params:**
- `query` (string, required): Search query
- `platform` (string, optional): Filter by platform
- `category` (string, optional): Filter by category (e.g. "marketing", "development")
- `minSecurityScore` (number, optional): Minimum security score 0-100
- `limit` (number, optional): Max results, default 5, max 20

**Endpoint:** `GET /api/agent/search?q=...&limit=...&platform=...&category=...&minSecurityScore=...`

**Response fields used:** `results` array (not `data`), `total`. Each result: `name`, `slug`, `description`, `owner`, `platforms`, `installCount`, `score`, `ratingCount`, `securityScore`, `contentQualityScore`.

**Output format:**
```
1. **Skill Name** (`slug`)
   Description text
   Owner: x | Installs: 1,234 | Rating: 4.2/5 (10 ratings)
   Security: 92/100 | Quality: 78/100
   Platforms: claude-code, cursor
   Install: use install_skill with slug "slug"
```

### Updated: `get_skill`

Get full details for a specific skill.

**Params:** `slug` (string, required)

**Endpoint:** `GET /api/skills/:slug`

**Additional fields surfaced (vs v0.1.0):**
- `securityScore`, `securityVerdict` (verdict + confidence + reasoning)
- `contentQualityScore`
- `qualityReview.score`
- `originalAuthor` (if skill is a copy)
- `claimed` / `claimedBy`
- `jobRoles`, `jobCategories`
- `updatedAt`

**Output format:** Markdown sections for metadata, security analysis, quality review, then SKILL.md content.

### Updated: `install_skill`

Install a skill from agentskill.sh.

**Params:**
- `slug` (string, required): Skill slug
- `targetDir` (string, optional): Override install directory

**Endpoint change:** Switch from `GET /api/skills/:slug` + manual write to `GET /api/agent/skills/:slug/install`.

This endpoint returns: `slug`, `name`, `owner`, `description`, `skillMd`, `skillFiles`, `skillFolder`, `installPath`, `contentSha`, `securityScore`, `securityVerdict`, `contentQualityScore`.

**Security gate:** If `securityVerdict.verdict` is `MALICIOUS`, refuse to install and show the reasoning. If `SUSPICIOUS`, install but warn.

**Install tracking:** `POST /api/skills/:slug/install` with `{ platform: "mcp", agentName: "agentskill-mcp" }` (fire and forget, same as before).

### Updated: `get_trending`

Get trending/popular skills.

**Params:**
- `period` (enum, optional): `hot` (24h), `trending` (7d), `top` (all time), `latest` (newest). Default: `trending`.
- `platform` (string, optional): Filter by platform
- `limit` (number, optional): Default 10, max 20

**Endpoint:** `GET /api/skills?section=...&limit=...&platform=...`

**Output:** Same format as search results, with security/quality scores.

### New: `browse_skillsets`

Browse curated skill collections.

**Params:**
- `query` (string, optional): Search skillsets by name/description
- `limit` (number, optional): Default 10, max 20

**Endpoint:** `GET /api/skillsets`

**Output format:**
```
1. **Skillset Name** (`slug`)
   Description
   Author: x | Skills: 5 | Installs: 234
   Avg Security: 90/100 | Avg Quality: 75/100
   Install: use install_skillset with slug "slug"
```

### New: `install_skillset`

Install all skills in a curated skillset.

**Params:**
- `slug` (string, required): Skillset slug
- `targetDir` (string, optional): Override install directory

**Endpoint:** `GET /api/agent/skillsets/:slug/install`

**Behavior:** Iterates over all skills in the skillset, writes each to its own subdirectory. Shows summary of what was installed. Tracks install via `POST /api/skillsets/:slug/install`.

**Security:** Skip any skill with `MALICIOUS` verdict. Warn on `SUSPICIOUS`.

### New: `rate_skill`

Rate an installed skill.

**Params:**
- `slug` (string, required): Skill slug
- `rating` (number, required): 1-5
- `comment` (string, optional): Optional feedback

**Endpoint:** `POST /api/skills/:slug/agent-feedback` with `{ rating, comment, agentName: "agentskill-mcp" }`

### New: `check_updates`

Check remote versions for a list of skills (so agents can compare with their local copies).

**Params:**
- `slugs` (string[], required): Array of skill slugs to check

**Endpoint:** `GET /api/agent/skills/version?slugs=slug1,slug2,...`

**Output:** For each slug: `contentSha` and `updatedAt`. The calling agent is responsible for comparing against local files to determine if an update is needed.

## API Client

- User-Agent: `agentskill-mcp/0.2.0`
- No auth required
- Same error handling (throw on non-2xx)

## Package Changes

- Version: `0.1.0` -> `0.2.0`
- No new dependencies
- No structural changes (single `src/index.ts`)

## Out of Scope

- Authentication/API keys
- `remove_skill` tool (trivial fs operation)
- `list_skills` local tool (filesystem scanning, platform-dependent)
- MCP resources or prompts
- Multi-file restructuring
